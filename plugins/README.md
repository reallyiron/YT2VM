# plugins/

Installed plugins live here, one folder per plugin (`plugin.json` + `plugin.py`).

- Install from the **Plugin Market** page in the app, or drop a plugin folder here and press **Reload all** on the **Plugins** page.
- Writing your own: [docs/plugins.md](../docs/plugins.md)
- Using and publishing to the market: [docs/plugin-market.md](../docs/plugin-market.md)
