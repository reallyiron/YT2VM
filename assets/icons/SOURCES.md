# Overlay icons

These files are used unchanged (the two logos are wrapped in a plain `<svg>` tag with their original size, as Iconify exports them). YT2VM also keeps a copy of each one inside `yt2vm.py`, so the overlays work even if this folder is missing. If a file here exists, the overlay server uses it instead, so you can swap an icon by replacing its file.
